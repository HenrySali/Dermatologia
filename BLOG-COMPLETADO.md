## 🖼️ Para Agregar Imágenes Reales:

Reemplaza:
```html
<div class="article-image-placeholder">
    <span>🔬 Imagen: Tipos de Acné</span>
</div>
```

Con:
```html
<div class="article-image">
    <img src="/blog/images/acne-tipos.jpg" alt="Tipos de Acné">
</div>
```

Y agrega CSS:
```css
.article-image img {
    width: 100%;
    height: auto;
    border-radius: 10px;
    margin: 20px 0;
    box-shadow: var(--shadow);
}
```
